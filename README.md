# 🍄 Mario Jump Game

A simple and fun **Mario-style browser game** built using **HTML, CSS, and JavaScript**.

The objective is simple: control Mario, jump over obstacles, survive as long as possible, and achieve the highest score! 🎮

## 🎮 Features

* 🏃 Mario left and right movement
* 🦘 Jump functionality
* 🚧 Moving obstacles
* 💥 Collision detection
* 🏆 Score system
* ⭐ High score tracking
* ⏸️ Pause and resume
* 🔄 Restart after Game Over
* 📈 Increasing difficulty
* 📱 Responsive design
* 🎨 Simple and clean UI

## 🕹️ Controls

| Key     | Action         |
| ------- | -------------- |
| `←`     | Move Left      |
| `→`     | Move Right     |
| `A`     | Move Left      |
| `D`     | Move Right     |
| `SPACE` | Jump           |
| `W`     | Jump           |
| `↑`     | Jump           |
| `P`     | Pause / Resume |
| `ENTER` | Restart        |

## 🚀 How to Run

### Option 1 — Open Directly

Simply open:

```text
index.html
```

in your browser.

### Option 2 — VS Code

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Start playing! 🎮

## 🎯 How to Play

1. Start the game.
2. Use `A` / `D` or the arrow keys to move.
3. Press `SPACE` or `↑` to jump.
4. Avoid the obstacles.
5. Your score increases when you pass obstacles.
6. The obstacle becomes faster as your score increases.
7. If Mario hits an obstacle, the game ends.
8. Click **Start Over** to play again.
